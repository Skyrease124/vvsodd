# Location coverage of the published map datasets

Generated by `node tools/coverage/location-coverage.mjs` from the published files in `kinvest-liens/map/data/`, the official parcel sources in `netlify/lib/gis-sources.mjs`, the owner-side audits in `netlify/lib/data/parcel-matches/` and the Florida registry in `netlify/lib/data/florida-gis-registry.json`. `tests/location-coverage.test.mjs` fails if this file is out of date.

- **Located**: records whose published file carries a position (`cx`). **Boundary**: records with a parcel outline (`g`). **Unlocated**: records with no position.
- Owner-approved positions are kept on the server until the 48-hour Pro early-access window ends. They are not in the published counts; the audit column shows them where an audit exists.
- **Candidate**: an official position that the owner has not checked yet. Candidates stay on the server and are never published. A county's "no position" count is the records with no official position at all.
- These counts describe the files in the repository. They are not a live count of what a visitor sees.
