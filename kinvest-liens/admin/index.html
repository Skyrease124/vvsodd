How it works

  • Your key is checked with NVIDIA, then saved on the server. It is never shown on any web page and never put in the website code.
  • You need the setup code I gave you. Without it, nobody can save or remove a key.
  • If a key is also set in Netlify’s environment variables, that one is used first.
  • Set a spending limit in your NVIDIA account. The question box also limits each visitor and caps questions per day.
