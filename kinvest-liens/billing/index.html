    How it works

    • Keys are checked with Stripe, then saved on the server. They are never shown on a page or put in the website code.
    • Use a test key first. No real money moves in test mode. When you go live, save your live key here and tap “Create the $5.50/week plan” again, and add a live webhook the same way.
    • A key set in Netlify’s environment variables (STRIPE_SECRET_KEY, STRIPE_WEBHOOK_SECRET) is used first.
    • Stripe emails receipts and invoices; turn that on in Stripe under Settings → Customer emails.
