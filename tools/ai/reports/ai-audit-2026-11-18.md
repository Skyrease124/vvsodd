# AI research engine audit (2026-11-18)

## Existing AI (kept, not replaced)
- `netlify/functions/ai.mjs`: Pro only (server-checked). Three steps: question becomes a whitelisted JSON search (rules first, model only if needed), our code runs it over the site's own data, the model writes a short answer using only the rows found. Rows are shown beside the answer.
- Data it can search: state rules for 50 states + DC, individual liens for the counties we carry (17,482 records), NYC history, FL owner location (Pro roll), weather/crime/parks/energy/fire by place.
- Safeguards already present: no invented numbers rule, "Verify" line, no advice or return predictions, per-member and global daily caps (security audit), key kept on the server.

## Improvements in this branch
1. **Portfolio intelligence.** Questions like "Which of my certificates have upcoming deadlines?", "How much have I invested in Florida?", "Compare my estimated returns by county", "Which properties need more research?" are answered by code from the signed-in member's own portfolio. No model call, so no AI spend and no invented numbers. Dates are labeled "deadline you entered" or "estimate". Returns are labeled an estimate, not a prediction.
2. **Isolation proven.** `tools/security/portfolio-ai.mjs`: a Pro member never sees another member's entries; Free, expired and signed-out are refused; zero model calls.
3. **Source registry.** `netlify/lib/source-registry.mjs`: 17 sources with owner, coverage, access method, reliability class, update frequency and limits. 13 are wired into the site; 4 are listed as planned and flagged not integrated (CO statewide parcels, AZ ADWR parcels, state revenue pages, land banks). Answers now return their sources and the AI page shows them as links.
4. **Accuracy test.** `tools/security/ai-accuracy.mjs`: 4 searches in FL, CO, AZ returned 32 liens; every parcel and tax amount was found in the county list files (0 missing).
5. AI page gets a "My deadlines" quick question and a source line.

## Test results
- New: portfolioai unit test, source registry test, portfolio isolation (7/7), accuracy (32/32).
- Existing: all Netlify tests and the security suite still pass (spend cap: 40 parallel requests, 3 accepted).

## Coverage honestly stated
- Lien lists: 30 counties (see `FILES` in screen.mjs). Full statute-checked courses: FL, TX, AZ, IA, MI, CO. Other states answer from state summary data and are flagged "verify".
- Live-record checks (parcel record, flood, wetlands, elevation, soil) work where the existing integrations cover the parcel; the AI says when data is unavailable.

## Not done yet (needs more development or your decision)
- Natural-language search over all counties nationwide: only counties we hold lists for. Other counties need imports (LienHub/county exports).
- "Road access", HOA status: only where pre-checked flags exist; HOA feature is still a pending task.
- AI report generator with PDF/CSV (a Property Report exists for Miami-Dade and Palm Beach only; not extended).
- Result cards with map and save-to-portfolio actions in the AI page.
- Persistent caching and an API-usage dashboard for external calls; per-source quotas beyond the AI daily cap.
- Source registry is not yet read automatically to refresh data.
- Cost estimate: not measured against real provider billing. Portfolio and weather/record answers cost no model tokens; other questions use 1 to 2 model calls each, capped at 120 per member per day.

## Update: research reports and cards
- `aireport.mjs` (Pro only, 60 per hour): 10-section report for a listed parcel, JSON or CSV. Every line is labeled Verified, Estimate, Missing or To do; verification dates, official links, due diligence checklist and a "not a title search, appraisal or legal advice" notice are included. No model call, no AI spend.
- `/ai/report/` page: mobile layout, "Print or save as PDF" (browser print) and "Download CSV". Result cards in the AI page now have a "Research report" button next to Show on map and Save to portfolio.
- Test `tools/security/aireport.mjs`: 10/10 (Pro ok, CSV, unknown parcel 404, Free/expired/signed-out refused, no scores or promises). Screenshot: `report-mobile.png`.
- Limits: report covers parcels on our county lists only; elevation, zoning and HOA are shown as Missing; "PDF" is the browser print dialog, not a server-made file.
