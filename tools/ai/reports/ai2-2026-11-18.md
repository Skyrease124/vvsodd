# AI 2.0 (implementation report, 2026-11-18)

## What was built
| Stage | What | Tool |
|---|---|---|
| 1. Knowledge | 443 searchable passages from our own state rules, course lessons and source registry, each keeping its source link and checked date. Index saved in the site database (Netlify Blobs) by content hash; built in ~0.3 s if missing | LlamaIndex (`@llamaindex/core`: Document, SentenceSplitter, BaseRetriever) + BM25 search, free, no embeddings, no outside calls |
| 2. Agent | Understand, Plan, Retrieve, Verify (retry once with fewer filters if nothing matched), Analyze, Report | LangGraph (`@langchain/langgraph`) |
| 3. Verify | Exact parcel lookup across all 30 county lists (never fuzzy), historical sale dates, stale lists (>30 days), missing price/value/flood checks, states flagged "sources differ" | plain code |
| 4. Performance and cost | Repeat research served from a saved result (6 h), no model call; at most 2 model calls per new question; same per-member and global daily caps as before (slot taken before any work) | existing NVIDIA integration |
| 5. UI | "How I researched this" steps, "What I could not confirm" box, sources, state table and lien cards | |

Old one-shot path is untouched and still handles simple questions; send `classic:true` to force it. If the agent fails it falls back to the old path.

## Evaluated, not integrated
- **Browser Use / Firecrawl**: not added. Our 30 county lists are already imported, and live scraping of county sites hits 403s and terms limits (the audit found 19 of 30 county pages refuse automated requests). Revisit only for a specific county with a permitted public feed.
- **LlamaIndex embeddings / vector index**: not added; BM25 is free and enough for 443 passages. Embeddings would add per-request cost.

## Before and after (model switched off so only our records show)
- "Compare tax lien opportunities in Florida, Arizona and Colorado": before, "Here is what the data shows." plus a table. After: 8 steps, rules for 3 states, lien lists held (AZ 1,509, CO 3,503, FL 5,151 liens, with counties), sources.
- "Research the risks of buying tax liens in Texas": before, a lien search with nothing useful. After: says we hold no Texas county list (rules and course passages only), lists it as uncertainty.
- "Investigate parcel 99-99-99-99-99-999-9999": before, an unrelated list. After: "not on any county list we carry; I will not guess", no unrelated passages.
- Real parcel (Larimer 9402111001): exact record, amount $11, land value $500, sale date 2026-11-19, list checked 2026-11-11, link to the county list.

## Tests
- agent unit test (6 scenarios), knowledge test, security test `tools/security/agent.mjs`: anon 401, Free 402, expired 402, Pro gets 8-step research, repeat served from cache with 0 model calls, no member portfolio data in research output, owner allowed, spend cap holds under 40 parallel requests.
- All existing Netlify tests and the security suite pass.

## Limits (honest)
- No live NVIDIA key in this environment: model phrasing tested with a stand-in model, so real answer wording is not yet seen. Deploy preview uses the live key.
- Research covers our data: 30 counties, 6 full state courses, rules for 50 states. It does not browse live county sites.
- Parcel lookup is exact (formatting differences ignored); a parcel on a county we do not carry is reported as not found.
- Added dependencies: @langchain/langgraph, @langchain/core, @llamaindex/core (~32 MB installed); check function cold-start on the preview.
