# Education system audit (2026-11-18)

Scope: step 1 of the Master Class upgrade. Read-only; nothing changed on the site.

## What exists today
- 6 full published state courses (FL, TX, AZ, IA, MI, CO): 12 modules each, 30 to 35 lessons, 36 quiz questions, a Bid or Pass exercise, glossary, checklists, inline statute citations (133 to 213 per course), last checked 2026-11-11.
- Module 1 of each course is free; the other modules, quizzes and exercise are members only, enforced on the server (course.mjs returns 403).
- Progress is saved to the member account (user.course); signed-out visitors keep it in the browser.
- A short generated state class exists for every state (learn/state), built from the site's own checked state data.
- A 51-row tracker (50 states + DC) records research, writing, review and publication status.

## Coverage (51 rows)
- Full course published: 6 (Arizona, Colorado, Florida, Iowa, Michigan, Texas)
- Research blocked by an unreadable official source: 3 (California, Georgia, Illinois)
- Partial research (sale steps sourced, statute not fully read): 33
- Research not started: 9 (Alaska, Connecticut, Hawaii, Massachusetts, Nevada, Pennsylvania, South Dakota, Vermont, Wisconsin)

## Gaps against the request
| Request | Status |
|---|---|
| 10 chapters per state | Existing courses use 12 modules covering all 10 topics; the 44 other states have only a short class |
| County education | Counties exist as listing data; no per-county course page with registration, auction schedule, GIS links |
| Chapter progress, quizzes, saved progress | Done in the 6 full courses |
| Learning paths (beginner, intermediate, advanced) | Missing |
| Searchable glossary | Per-course glossary exists (11 to 19 terms), not searchable, no national glossary |
| Calculation exercises | One Bid or Pass exercise per course; no stand-alone calculator drills |
| Source links and last-reviewed dates | Done in full courses; short classes show source links only |
| Free vs Pro | Server enforced; preview of locked lessons shows title only |

## Risks found
- Short classes for 44 states are generated from summary data, so they are not course-grade; they must stay labeled as summaries.
- Blocked states cannot be written accurately until an official source is readable (CA, GA, IL; NJ partial). Nothing will be invented.
- Existing courses were self-checked, not reviewed by a lawyer. Statutes change; the 2026-11-11 check date will age.

## Proposed order
1. Keep FL as the reference. Add learning paths, searchable national glossary and calculator drills (all states, small, safe).
2. Add county pages for counties we already carry, using official links only.
3. Add full courses state by state, only after the official statute is read, in the tracker batch order.
4. Flag any course older than 90 days as needing review.
